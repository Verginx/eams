## 1. 术语说明

## 2. 业务域

| 术语 | 英文/缩写 | 类别 | 说明 |
|------|-----------|------|------|
| 教务管理系统 | EAMS | 产品 | Education Administration Management System，本项目系统名 |
| 学生 | Student | 实体 | 系统管理对象之一，可注册、选课、分班 |
| 教师 | Teacher | 实体 | 系统管理对象之一，可授课、担任班主任 |
| 班级 | Class | 实体 | 学生归属单位，含班主任 |
| 课程 | Course | 实体 | 教学单元，含学分与授课教师 |
| 选课 | Course Selection | 业务操作 | 学生与课程建立绑定关系 |
| 退课 | Course Unselect | 业务操作 | 解除学生与课程的绑定 |
| 分班 | Class Assignment | 业务操作 | 为学生指定所属班级 |
| 课时费总额 | Class Fee Total | 属性/计算值 | 课时费总额 = 课时费单价 × 所带学生数 |
| 成绩登记 | Score Entry | 业务操作 | 为某学生某门课录入成绩 |
| 班主任 | Head Teacher | 业务关系 | 班级关联的教师 |
| 授课教师 | Course Teacher | 业务关系 | 课程关联的教师 |
| 职称 | Professional Title | 实体 | 教师专业技术等级（初级/中级/副高级/高级），按级别倒序展示关联教师 |
| 选老师 | Assign Teacher | 业务操作 | 为学生指定一名教师（students.teacher_id），区别于按授课课程统计的所带学生数 |
| 年级 | Grade | 属性 | 高一 / 高二 / 高三 |
| 学分 | Credit | 属性 | 课程学分（1-10） |
| 角色 | Role | 属性 | 用户角色：admin（管理员）/ student（学生） |
| 逻辑删除 | Soft Delete | 数据状态 | 删除学生时置 is_deleted=1 移入回收站，非物理删除 |
| 回收站 | Recycle Bin | 业务操作 | 存放逻辑删除学生，可恢复或永久删除（管理员操作，需 X-Current-Role: admin 头） |
| 未分班 | Unassigned | 状态 | class_id 为空的学生的班级状态 |
| 满员课程 | Full Course | 状态 | 已选人数达到上限（enrolled_count ≥ max_students）的课程，前端置灰禁选 |
| 种子数据 | Seed Data | 数据 | init.sql 初始化的演示数据 |

## 3. 技术域

| 术语 | 英文/缩写 | 类别 | 说明 |
|------|-----------|------|------|
| Web 框架 | FastAPI | 技术 | Python 异步 Web 框架，本项目后端 |
| ASGI 服务器 | Uvicorn | 技术 | 本地运行应用的 ASGI 服务器 |
| MySQL 驱动 | PyMySQL | 技术 | 纯 Python 的 MySQL 客户端驱动 |
| 每次新建连接 |  / 连接 | 技术 | 复用数据库连接、提升性能 |
| 数据校验 | Pydantic | 技术 | 请求参数/响应数据校验与类型约束 |
| 环境配置 | pydantic-settings | 技术 | 从环境变量 / .env 读取配置 |
| 明文密码 | Plaintext Password | 技术 | 密码明文存储、登录时明文比对（教学演示，无哈希/token） |
| 密码强度 | Password Strength | 技术 | 密码须 8-30 位含大小写字母+数字+特殊字符；前端实时评估等级（弱/一般/中等/强/很强） |
| 忘记密码 | Forgot Password | 技术 | 用户名验证 + 密码重置两步流程（/auth/check-username、/auth/reset-password） |
| 无鉴权 | No Auth | 技术 | 教学演示，所有接口可直接访问，无 JWT/token |
| 接口文档 | Swagger / OpenAPI | 技术 | `/docs` 在线交互文档 |

## 6. 前端与数据库

| 术语 | 英文/缩写 | 类别 | 说明 |
|------|-----------|------|------|
| 业务日志 | app.log | 运维 | 记录登录/注册/增删改/选课等操作，按天滚动保留 7 天 |
| 明文登录 | - | 安全 | 用户名密码直接比对（教学演示，无哈希/token） |
| 侧边栏 | Sidebar | 前端 | 后台左侧导航菜单 |
| 弹框 | Modal | 前端 | 新增/修改/绑定操作使用的弹出窗口 |
| 分页 | Pagination | 前端 | 学生列表分页浏览（上一页/下一页/页码） |
| 关键字查询 | Keyword Search | 前端 | 按名称模糊过滤列表 |
| 下拉/勾选绑定 | Dropdown/Checkbox Binding | 前端 | 分班通过下拉选择、选课通过勾选/下拉绑定 |
| 图表库 | ECharts | 前端 | Apache 开源图表库，首页展示柱状图（班级人数）与饼状图（男女占比） |
| Toast 提示 | Toast | 前端 | 3 秒自动消失的轻提示组件，替代 alert 弹窗 |
| 防重复提交 | Submit Lock | 前端 | 弹框确定按钮提交期间置灰，防止双击重复提交 |
| XSS 转义 | esc() | 前端 | 将 `<>&"'` 等字符转义为 HTML 实体，防止注入 |
| 本地存储 | localStorage | 前端 | 浏览器保存登录信息（用户名/角色） |
| 建表脚本 | init.sql | 数据库 | 建库建表 + 种子数据脚本 |
| 级联删除 | Cascade Delete | 数据库 | 删除主记录连带清理关联记录（逐条执行） |
| 课程人数上限 | max_students | 数据库 | 课程可选学生数量上限，达满员（enrolled_count ≥ max_students）后前端置灰禁选 |
