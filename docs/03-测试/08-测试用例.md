> 测试方式：使用 **Apifox** 接口测试工具执行下列用例（系统无鉴权，无需登录/token）。

---

## 1. 用例总览

在 Apifox 中导入接口后，逐条执行下列用例，覆盖认证、各模块 CRUD、查询/分页、选课/分班、参数校验与级联删除。用例编号规则：`<模块>-<序号>`。

## 2. 认证模块

| 编号 | 接口 | 步骤（Apifox 发送） | 预期结果 |
|------|------|------|---------|
| AUTH-01 | POST /auth/register | 合法注册数据（用户名/密码/姓名/性别/年龄） | 200，code=0，返回 student_id |
| AUTH-02 | POST /auth/register | 注册已存在用户名 | 400 `用户名已存在` |
| AUTH-03 | POST /auth/register | 空请求体 | 422 `参数校验错误` |
| AUTH-04 | POST /auth/login | admin / admin123 | 200 登录成功，返回用户信息 |
| AUTH-05 | POST /auth/login | 错误密码 | 400 `用户名或密码错误` |
| AUTH-06 | POST /auth/register | 用户名<3 / 密码<6 / 年龄越界 | 422 `参数校验错误` |

## 3. 学生模块

| 编号 | 接口 | 步骤 | 预期结果 |
|------|------|------|---------|
| STU-01 | GET /students/page | page_size=2 | 200，data 含 {total, items} |
| STU-02 | GET /students/page | keyword=张 | 命中姓名含"张"的学生 |
| STU-03 | GET /students/page | page=2 | 第二页数据 |
| STU-04 | GET /students/one/{id} | id=999 | 404 `学生不存在` |
| STU-05 | POST /students/add | 合法数据 | 200 code=0 |
| STU-06 | POST /students/add | 指定不存在班级 class_id | 404 `班级不存在` |
| STU-07 | PUT /students/update/{id} | 合法修改 | 200 code=0 |
| STU-08 | PUT /students/assign-class/{id} | class_id 合法 | 200 `分班成功` |
| STU-09 | GET /students/all | 学生列表 | 200 返回列表（含授课教师名 teacher_names） |
| STU-10 | DELETE /students/del/{id} | 删除学生 | 200 删除成功；查库确认选课/账号已清理 |

## 4. 教师 / 班级 / 课程

| 编号 | 接口 | 步骤 | 预期结果 |
|------|------|------|---------|
| TEA-01 | GET /teachers/all | - | 200 返回教师列表 |
| TEA-02 | GET /teachers/all | keyword=张 | 按姓名过滤 |
| TEA-03 | POST /teachers/add | 合法数据 | 200 code=0 |
| TEA-04 | PUT /teachers/update/{id} | 合法修改 | 200 code=0 |
| TEA-05 | DELETE /teachers/del/{id} | 删除教师 | 200 删除成功 |
| CLS-01 | GET /classes/all | - | 200 返回班级列表（含班主任名） |
| CLS-02 | GET /classes/all | keyword=高一 | 按班级名过滤 |
| CLS-03 | POST /classes/add | 合法数据 | 200 code=0 |
| CLS-04 | POST /classes/add | 指定不存在班主任 | 404 `班主任教师不存在` |
| CLS-05 | PUT /classes/update/{id} | 合法修改 | 200 code=0 |
| CLS-06 | DELETE /classes/del/{id} | 删除班级 | 200 删除成功 |
| COU-01 | GET /courses/all | - | 200 返回课程列表 |
| COU-02 | GET /courses/all | keyword=数 | 按课程名过滤 |
| COU-03 | POST /courses/add | 合法数据 | 200 code=0 |
| COU-04 | PUT /courses/update/{id} | 合法修改 | 200 code=0 |
| COU-05 | DELETE /courses/del/{id} | 删除课程（有学生仅选此课程） | 400 阻止删除；非唯一课时 200 且查库确认选课清理 |

## 5. 选课与其它

| 编号 | 接口 | 步骤 | 预期结果 |
|------|------|------|---------|
| COU-06 | GET /courses/student/{sid} | 查询学生选课 | 200 返回该学生已选课程 |
| COU-07 | POST /courses/select/{sid} | 选一门课 | 200 `选课成功` |
| COU-08 | POST /courses/select/{sid} | 重复选同一课 | 400 `该课程已选过，不能重复选` |
| COU-09 | DELETE /courses/unselect/{sid} | 退一门课（非最后一门） | 200 `退课成功` |
| COU-09B | DELETE /courses/unselect/{sid} | 退掉最后一门课程 | 400 `每个学生至少选择一门课程，不能退掉最后一门课程` |
| COU-10 | PUT /courses/score/{sid} | 登记成绩 | 200 `成绩登记成功` |
| SYS-01 | GET / | 访问根路径 | 307 重定向到 `/static/login.html` |
