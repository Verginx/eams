## 1. 用例总览

在 Apifox 中导入接口后，逐条执行下列用例，覆盖认证、各模块 CRUD、查询/分页、选课/分班、参数校验与级联删除。用例编号规则：`<模块>-<序号>`。

## 2. 认证模块

| 编号 | 接口 | 步骤（Apifox 发送） | 预期结果 |
|------|------|------|---------|
| AUTH-01 | POST /auth/register | 合法注册数据（用户名/密码/姓名/性别/年龄） | 200，code=0，返回 student_id |
| AUTH-02 | POST /auth/register | 注册已存在用户名 | 400 `用户名已存在` |
| AUTH-03 | POST /auth/register | 空请求体 | 422 `参数校验错误` |
| AUTH-04 | POST /auth/login | admin / admin123 | 200 登录成功，返回用户信息 |
| AUTH-05 | POST /auth/login | 错误密码 | 400 `用户名或密码错误` |
| AUTH-06 | POST /auth/register | 用户名<3 / 密码<6 / 年龄越界 | 422 `参数校验错误` |
| AUTH-07 | POST /auth/check-username | 存在的用户名 | 200 code=0，返回 `存在` |
| AUTH-08 | POST /auth/check-username | 不存在的用户名 | 404 `用户名不存在` |
| AUTH-09 | POST /auth/reset-password | 合法新密码（8-30 含大小写字母+数字+特殊字符） | 200 `密码重置成功` |
| AUTH-10 | POST /auth/reset-password | 弱密码（缺大小写/数字/特殊字符） | 422 `参数校验错误`（密码强度不满足） |
| AUTH-11 | POST /auth/password-strength | body：{password} | 200，返回 level/label/color/percent/valid |

## 3. 学生模块

| 编号 | 接口 | 步骤 | 预期结果 |
|------|------|------|---------|
| STU-01 | GET /students/page | page_size=2 | 200，data 含 {total, items} |
| STU-02 | GET /students/page | keyword=张 | 命中姓名含"张"的学生 |
| STU-03 | GET /students/page | page=2 | 第二页数据 |
| STU-04 | GET /students/one/{id} | id=999 | 404 `学生不存在` |
| STU-05 | POST /students/add | 合法数据 | 200 code=0 |
| STU-06 | POST /students/add | 指定不存在班级 class_id | 404 `班级不存在` |
| STU-07 | PUT /students/update/{id} | 合法修改 | 200 code=0 |
| STU-08 | PUT /students/assign-class/{id} | class_id 合法 | 200 `分班成功` |
| STU-09 | GET /students/all | 学生列表 | 200 返回列表（含所选老师名 teacher_name） |
| STU-10 | DELETE /students/del/{id} | 删除学生 | 200 删除成功；查库确认移入回收站（is_deleted=1） |
| STU-11 | PUT /students/assign-teacher/{id} | body：{teacher_id} 合法教师 | 200 `选老师成功`；列表展示所选老师 |
| STU-11B | PUT /students/assign-teacher/{id} | body：{teacher_id: null} | 200 清空所选老师 |
| STU-12 | GET /students/recycle/list | 需请求头 X-Current-Role: admin | 200 返回回收站学生列表（按删除时间倒序） |
| STU-13 | PUT /students/recycle/recover/{id} | 需 admin 头 | 200 `已从回收站恢复`；列表恢复正常 |
| STU-14 | DELETE /students/recycle/real-del/{id} | 需 admin 头 | 200 `已永久删除，不可恢复`；查库确认选课/账号已清理 |
| STU-15 | GET /students/recycle/list | 无 X-Current-Role 头（非 admin） | 403 `仅管理员可操作回收站` |
