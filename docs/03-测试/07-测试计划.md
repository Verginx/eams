## 1. 测试目标

通过 Apifox 验证 EAMS 系统满足《软件需求规格说明书（SRS）》的功能与非功能需求，覆盖认证、各管理模块 CRUD、查询分页、选课/分班/选老师、参数校验与级联删除等关键路径。

## 2. 测试范围

### 2.1 覆盖

- 接口层：38 条路径（含根路径）的功能正确性、参数校验、错误响应（400/404/422/500）
- 业务层：注册/登录、学生/教师/课程/班级/职称 CRUD、分班、选老师、选课、退课、成绩登记、查看学生选课
- 数据层：级联删除（删学生/删课程连带清理）、重复选课拦截

### 2.2 不覆盖 / 受限

- 系统无鉴权（教学演示），不涉及登录态/token 测试
- 学生自助选课（学生角色自助选课页）未在本次范围，不在本期功能验收
- 前端页面交互（弹框/下拉/分页展示）通过浏览器手动验证

## 3. 测试环境

| 项 | 配置 |
|----|------|
| 操作系统 | Windows 10/11 |
| 运行时 | Python 3.10+（.venv 虚拟环境） |
| 数据库 | MySQL 8.0（127.0.0.1:3306，school_db，init.sql 初始化） |

| 测试工具 | Apifox（桌面版或 Web，用于接口测试） |

## 4. 测试策略

| 类型 | 方法 | 工具 |
|------|------|------|
| 接口测试 | Apifox 导入 openapi.json 自动生成接口，逐接口发送并校验响应 | Apifox |
| 参数校验 | 空/越界字段请求 → 422 envelope | Apifox |
| 错误分支 | 不存在资源 → 404；重复选课 → 400 | Apifox |
| 级联删除 | 删学生/删课程后查库确认关联记录清理 | Apifox + MySQL |
| 前端交互 | 手动走通注册→登录→后台各操作 | 浏览器 |

### Apifox 使用步骤

1. 启动服务：`uvicorn main:app`（或 `python main.py`）
2. Apifox 新建项目（如 "EAMS"）
3. 导入接口：项目设置 → 导入数据 → 选择 **OpenAPI/Swagger**，URL 填 `http://127.0.0.1:8000/openapi.json` → 自动生成全部接口
4. 配置环境：环境管理 → 新建环境，baseUrl 设为 `http://127.0.0.1:8000`
5. 逐接口发送请求，校验返回状态码与 `{code,msg,data}` 响应体；可用"断言"配置预期结果

## 5. 通过标准

- 关键路径（注册/登录/CRUD/查询/分页/选课/分班/选老师）在 Apifox 中全部返回正确结果
- 校验与错误分支返回正确的 envelope（400/404/422）
- 删除后级联数据清理正确、无脏数据
- 满足 SRS 验收标准（详见《项目总结与验收报告》逐条对照）

## 6. 缺陷管理约定

- 缺陷记录：现象、复现步骤、预期/实际结果、严重级别
- 优先级：P1（阻断）/ P2（主要）/ P3（次要）/ P4（建议）
- 修复后回归验证再关闭
