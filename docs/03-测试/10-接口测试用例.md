## 1. 概述

本文档定义后端**已开发 API 接口**的 Apifox 测试用例，覆盖认证、学生、教师、班级、课程/选课、系统六类接口。范围限定为接口行为测试（状态码、统一响应 envelope、参数校验、查询/分页参数、错误分支），不涉及 model 层/VO 内部逻辑。

## 2. Apifox 使用步骤

1. **启动服务**：在项目根执行 `uvicorn main:app`（或 `python main.py`），确认 `http://127.0.0.1:8000` 可访问
2. **新建项目**：打开 Apifox → 新建项目（如 "EAMS"）
3. **导入接口**：项目设置 → 导入数据 → 选择 **OpenAPI/Swagger** → URL 填 `http://127.0.0.1:8000/openapi.json` → 确认导入（自动生成全部接口与数据结构）
4. **配置环境**：环境管理 → 新建环境 → baseUrl 设为 `http://127.0.0.1:8000`
5. **执行用例**：逐接口选择环境发送请求，校验状态码与 `{code,msg,data}` 响应体；可在接口上配置"断言"自动校验预期结果
6. **批量执行**：Apifox 支持"测试套件"批量运行全部接口用例，便于回归

> 说明：系统无鉴权（教学演示），所有接口可直接访问，无需配置 Authorization 头。
