## 1. 引言

本文档依据《项目概述与范围说明书》编写，定义 EAMS 的功能需求、非功能需求、业务规则与验收标准，作为设计、开发、测试与验收的依据。

## 2. 功能需求

### 2.1 用户认证模块

| 编号 | 功能名称 | 需求说明 |
|------|---------|---------|
| AUTH-01 | 学生注册 | 填写用户名、密码、姓名、性别、年龄自主注册；用户名唯一，重复需提示；密码需 8-30 位且含大小写字母+数字+特殊字符（前端强度条实时提示）；密码明文存储（教学演示） |
| AUTH-02 | 用户登录 | 校验用户名密码；错误提示；校验通过即登录成功（明文比对，无 token、无鉴权） |
| AUTH-03 | 忘记密码 | 登录页「忘记密码」→ 输入用户名验证存在 → 输入新密码（强度校验）→ 重置成功回登录页 |

### 2.2 学生管理模块

| 编号 | 功能名称 | 需求说明 |
|------|---------|---------|
| STU-01 | 学生列表 | 展示班级、所选老师、选课数等关联信息；按姓名关键字查询；分页浏览（每页 10 条，上一页/下一页/页码，与查询组合生效） |
| STU-02 | 学生详情 | 按 ID 查询单个学生 |
| STU-03 | 新增学生 | 弹框新增，可同时指定班级与所选老师 |
| STU-04 | 修改学生 | 弹框修改姓名、性别、年龄、年级 |
| STU-05 | 学生分班 | 弹框下拉选择班级完成分班（仅限与学生同年级的班级，跨年级拦截） |
| STU-06 | 选老师 | 弹框下拉选择一名教师作为学生的老师 |
| STU-07 | 学生选课 | 勾选/下拉选择课程完成选课；同一课程不可重复选；每个学生至少选 1 门 |
| STU-08 | 删除学生 | 逻辑删除移入回收站（记录操作人/删除时间），不物理删除 |
| STU-09 | 回收站 | 管理员查看回收站列表、恢复学生、真实删除（物理删除并清理选课记录与账号，不可恢复） |

## 3. 非功能需求

| 类别 | 需求说明 |
|------|---------|
| 安全 | 密码明文存储（教学演示）；数据库配置经 .env 注入 |
| 数据一致性 | 删除学生/课程级联清理关联记录（逐条执行） |
| 容错性 | 全局异常统一处理，接口统一返回 `{code,msg,data}` |
| 可观测性 | 业务操作日志（app.log，登录/注册/增删改/选课等），按天滚动保留 7 天 |
| 前端交互 | 关键字查询、学生分页、新增/修改弹框、分班下拉绑定、选课勾选/下拉绑定、表单提交前校验（防 422） |
| 可维护性 | 业务模块分层（router/vo/model）+ 公共模块（common） |
| 易用性 | Swagger `/docs`、Web 后台可视化操作 |

## 4. 业务规则

- **注册规则**：用户名 3-20 位、密码 8-30 位且含大小写字母+数字+特殊字符、年龄 10-100，均必填
- **角色**：`admin`（管理员）/ `student`（学生，注册后自动生成学生记录与账号）
- **密码存储**：明文存储（教学演示），种子管理员 `admin/admin123` 可直接登录
- **选课唯一**：`(student_id, course_id)` 联合唯一，重复选课被拦截
- **至少一门课**：每个学生至少选择 1 门课程；退课不能退掉最后一门（400），删除课程若会使某学生降到 0 门则被阻止
- **学生老师**：学生老师 = 通过 `students.teacher_id` 直接关联的教师（选老师，一名教师可带多名学生）；与选课无关
- **课时费**：课时费总额 = 单价 × 所带学生数（所带学生数 = 选择该教师所授课程的去重学生数，经选课表统计），带生越多课时费越高
- **课程属性**：开课状态（开课/未开课）、授课方式（线上/线下）、人数上限（NULL 不限制）
- **回收站**：学生删除为逻辑删除（移入回收站），仅管理员可恢复或真实删除；真实删除连带清理选课记录与账号
- **职称**：教师专业技术等级（初级/中级/副高级/高级）；教师可暂不评定（zhicheng_id 为空）；删除职称时清空持有该职称教师的引用
- **级联删除**：删课程连带选课记录；删教师清空其授课课程/班主任班级/所带学生引用；删班级清空所属学生分班；删职称清空教师职称引用（逐条执行）
- **分班年级约束**：班级年级固定（高一/高二/高三），学生只能分到与其年级相同的班级，跨年级分班被拦截
- **一致性清理**：学生/班级改年级导致年级不匹配时，自动清空该生分班

## 5. 验收标准

1. 管理员可通过后台完成学生、教师、班级、课程、职称的增删改查
2. 学生可自主注册登录，注册后生成学生记录
3. 学生可完成分班、选课（每个学生至少选 1 门课程）
4. 学生可选课，重复选课被拦截，退课不能退到 0 门
5. 删除学生后其选课记录和账号一并清理（逐条执行）
6. 所有接口在 `/docs` 中可正常调用
7. 系统无鉴权，所有接口可直接访问
8. 密码明文存储（教学演示），无哈希无 token
9. Windows 本地按部署手册可跑通注册 → 登录 → 后台管理全流程
10. 登录后进入后台首页，显示欢迎语与统计，侧边栏可切换管理模块
11. 各列表支持按名称关键字查询；新增/修改通过弹框；分班通过下拉绑定、选课通过勾选/下拉绑定
12. 学生列表支持分页浏览，与关键字查询组合生效
13. 前端各表单提交前校验，空表单或非法输入给出中文提示，不触发后端 422 误报
