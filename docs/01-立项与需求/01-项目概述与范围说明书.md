## 1. 项目背景

传统学校教务管理依赖人工记录学生、教师、课程信息，存在数据分散、查询困难、无法在线办理等问题。本项目构建一套基于 Web 的教务管理系统，实现学生、教师、课程、班级的信息化管理，支持学生在线注册、选课、选老师、分班等核心教务流程。

## 2. 项目目标

1. 实现学生与教师信息的数字化管理（增删改查）
2. 支持学生在线自主注册与登录（用户名密码校验）
3. 支持学生选课、选老师、分班等教务核心功能
4. 提供 Web 管理后台与 API 接口文档

## 3. 项目范围

### 3.1 包含范围

| 模块 | 内容 |
|------|------|
| 用户认证 | 学生注册、登录（用户名密码校验）、角色（admin/student） |
| 学生管理 | 增删改查、分班、选老师、关键字查询、分页 |
| 教师管理 | 增删改查、关键字查询 |
| 班级管理 | 增删改查、关键字查询 |
| 课程与选课 | 课程增删改查、学生选课、查看学生选课、关键字查询 |
| 统计汇总 | 后台首页：欢迎语 + 学生/教师/课程/班级数量统计 |
| 系统基础 | 统一响应格式、全局异常处理、每次新建连接、业务日志、.env 配置 |

### 3.2 不包含范围（本期）

- 角色级权限细分（系统无鉴权，所有接口可直接访问）
- 退课、成绩登记的前端操作入口（后端接口已提供，前端待接）
- 移动端 / 小程序
- 多校区 / 多租户

## 5. 术语表

| 术语 | 说明 |
|------|------|
| 登录校验 | 用户名 + 密码比对，校验通过即登录成功（教学演示） |
| VO | Value Object，请求参数校验模型 |
| Envelope | 统一响应包装 `{code, msg, data}` |
| 分班 | 为学生指定所属班级 |
| 选课 | 学生与课程的绑定关系 |
