## 1. 概述

基础路径：`http://127.0.0.1:8000`。业务接口 37 个（加根路径共 38 条路径），在线文档 `/docs`（Swagger）可交互调试。

## 2. 统一响应格式

```
成功：{"code": 0, "msg": "提示信息", "data": <数据>}
失败：{"code": <HTTP状态码>, "msg": "错误信息", "data": null}
```

- `code = 0` 表示成功
- 错误 `code` 为对应 HTTP 状态码：400（业务校验）/ 404（资源不存在）/ 422（参数校验）/ 500（服务器内部）

> 说明：系统**无鉴权**（教学演示），除 `/auth/*` 外所有接口可直接访问，无需携带 token。
>
> 删除级联说明：删除教师会自动清空其授课课程（courses.teacher_id）、班主任班级（classes.head_teacher_id）、名下学生（students.teacher_id）的引用；删除班级会自动清空所属学生（students.class_id）的引用；删除职称会自动清空持有该职称教师（teachers.zhicheng_id）的引用；删除学生/课程会连带清理选课记录。

## 3. 接口清单

| 方法 | 路径 | 模块 | 说明 |
|------|------|------|------|
| GET | `/` | 系统 | 根路径：重定向到登录页 `/static/login.html` |
| POST | `/auth/register` | 认证 | 学生注册 |
| POST | `/auth/login` | 认证 | 用户登录（登录成功） |
| GET | `/students/all` | 学生 | 学生列表（?keyword= 按姓名模糊查询，全量） |
| GET | `/students/page` | 学生 | 学生分页列表（?keyword=&page=&page_size=，默认 page=1、page_size=10，返回 {total, items}） |
| GET | `/students/one/{id}` | 学生 | 学生详情 |
| POST | `/students/add` | 学生 | 新增学生 |
| PUT | `/students/update/{id}` | 学生 | 修改学生 |
| PUT | `/students/assign-class/{id}` | 学生 | 分班 |
| PUT | `/students/assign-teacher/{id}` | 学生 | 选老师 |
| DELETE | `/students/del/{id}` | 学生 | 删除学生 |
| GET | `/teachers/all` | 教师 | 教师列表（?keyword= 按姓名模糊查询；返回含 职称名 zhicheng_name、授课课程数 course_count、班主任班级数 class_count、名下学生数 student_count） |
| GET | `/teachers/one/{id}` | 教师 | 教师详情（同上含职称名与统计） |
| POST | `/teachers/add` | 教师 | 新增教师（body：{name, gender, age, subject, phone, zhicheng_id?, base_salary?, class_fee?, bonus?}） |
| PUT | `/teachers/update/{id}` | 教师 | 修改教师（body 同新增，含 zhicheng_id? 与薪资三字段） |
| DELETE | `/teachers/del/{id}` | 教师 | 删除教师 |
| GET | `/classes/all` | 班级 | 班级列表（?keyword= 按班级名模糊查询） |
| GET | `/classes/one/{id}` | 班级 | 班级详情 |
| POST | `/classes/add` | 班级 | 新增班级 |
| PUT | `/classes/update/{id}` | 班级 | 修改班级 |
| DELETE | `/classes/del/{id}` | 班级 | 删除班级 |
| GET | `/courses/all` | 课程 | 课程列表（?keyword= 按课程名模糊查询） |
| GET | `/courses/one/{id}` | 课程 | 课程详情 |
| POST | `/courses/add` | 课程 | 新增课程 |
| PUT | `/courses/update/{id}` | 课程 | 修改课程 |
| DELETE | `/courses/del/{id}` | 课程 | 删除课程 |
| GET | `/courses/student/{sid}` | 选课 | 查询学生已选课程 |
| GET | `/courses/students/{cid}` | 选课 | 查询某课程已选学生（含成绩，供成绩登记弹框） |
| POST | `/courses/select/{sid}` | 选课 | 学生选课（body：{course_id}） |
| DELETE | `/courses/unselect/{sid}` | 选课 | 学生退课（?course_id= 指定课程） |
| PUT | `/courses/score/{sid}` | 选课 | 成绩登记（body：{course_id, score}，score 0-100） |
| GET | `/stats/class-count` | 统计 | 各班级人数统计（柱状图数据源） |
| GET | `/stats/gender-ratio` | 统计 | 在校学生男女占比（饼状图数据源） |
| GET | `/zhicheng/all` | 职称 | 职称列表（?keyword= 按职称名模糊查询，按级别倒序；返回含 对应教师数 teacher_count、对应教师名 teacher_names） |
| GET | `/zhicheng/one/{id}` | 职称 | 职称详情 |
| POST | `/zhicheng/add` | 职称 | 新增职称（body：{name, level, description}） |
| PUT | `/zhicheng/update/{id}` | 职称 | 修改职称 |
| DELETE | `/zhicheng/del/{id}` | 职称 | 删除职称（清空持有该职称教师的职称引用） |

## 5. 查询与分页参数

| 接口 | 参数 | 类型 | 说明 |
|------|------|------|------|
| `GET /xxx/all` | keyword | string | 按名称模糊查询（LIKE），可选 |
| `GET /students/page` | keyword | string | 按姓名模糊查询，可选 |
| `GET /students/page` | page | int | 页码，默认 1 |
| `GET /students/page` | page_size | int | 每页条数，默认 10（钳制 1~100） |

分页返回示例：
```json
{"code": 0, "msg": "成功", "data": {"total": 6, "items": [{"id": 1, "name": "张三", ...}]}}
```

## 6. 典型请求/响应示例

### 6.1 登录
```
POST /auth/login
{ "username": "admin", "password": "admin123" }

200 {"code": 0, "msg": "登录成功",
     "data": {"user_id": 1, "username": "admin", "role": "admin", "student_id": null}}
```

### 6.2 参数校验失败
```
POST /auth/register   （缺字段）

422 {"code": 422, "msg": "参数校验错误", "data": [{"type":"missing","loc":["body","username"],...}]}
```

### 6.4 新增学生
```
POST /students/add
{ "name": "张三", "gender": "男", "age": 18, "grade": "高一", "class_id": null, "teacher_id": null }

200 {"code": 0, "msg": "新增成功", "data": {"id": 7}}
```
