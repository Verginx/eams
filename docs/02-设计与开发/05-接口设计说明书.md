## 1. 概述

基础路径：`http://127.0.0.1:8000`。业务接口 46 个（加根路径共 47 条路径），在线文档 `/docs`（Swagger）可交互调试。

## 2. 统一响应格式

```
成功：{"code": 0, "msg": "提示信息", "data": <数据>}
失败：{"code": <HTTP状态码>, "msg": "错误信息", "data": null}
```

- `code = 0` 表示成功
- 错误 `code` 为对应 HTTP 状态码：400（业务校验）/ 404（资源不存在）/ 422（参数校验）/ 500（服务器内部）

> 说明：系统**无鉴权**（教学演示），普通业务接口可直接访问，无需携带 token。所有请求可选携带 `X-Current-User`（操作用户名）、`X-Current-Role`（当前角色）请求头，供后端记录操作人与回收站权限校验；学生回收站相关接口（`/students/recycle/*`）**仅管理员可操作**，须携带 `X-Current-Role: admin` 头，否则返回 403。
>
> 删除级联说明：删除教师会自动清空其授课课程（courses.teacher_id）、班主任班级（classes.head_teacher_id）与所带学生（students.teacher_id）的引用；删除班级会自动清空所属学生（students.class_id）的引用；删除职称会自动清空持有该职称教师（teachers.zhicheng_id）的引用；删除课程会连带清理选课记录。学生删除为**逻辑删除**（移入回收站），回收站支持恢复与真实删除（真实删除会连带清理其选课记录与账号）。
>
> 选课与分班约束说明：学生老师 = 通过 `students.teacher_id` 直接关联（选老师，一名教师可带多名学生，学生列表展示「所选老师」）；选课通过选课表关联授课教师，与选老师相互独立。`assign-class` 只能选择与学生年级相同的班级（跨年级返回 400）；`students/add` 分班时校验班级年级一致；`classes/update` 变更年级会清空该班中年级不匹配学生的分班。每个学生**至少选择 1 门课程**：退课退到最后一门返回 400、删除课程若会使某学生降到 0 门则被阻止。教师「所带学生数」与课时费总额 = 单价 class_fee × 所带学生数（所带学生数 = 选择该教师所授课程的去重学生数，经选课表统计，与 `students.teacher_id` 的选老师无关）。

## 3. 接口清单

| 方法 | 路径 | 模块 | 说明 |
|------|------|------|------|
| GET | `/` | 系统 | 根路径：重定向到登录页 `/static/login.html` |
| POST | `/auth/register` | 认证 | 学生注册（含密码强度校验：8-30 位且含大小写字母+数字+特殊字符） |
| POST | `/auth/login` | 认证 | 用户登录（登录成功） |
| POST | `/auth/check-username` | 认证 | 忘记密码前置校验：确认用户名是否存在 |
| POST | `/auth/reset-password` | 认证 | 忘记密码 - 重置密码（body：{username, new_password}，含密码强度校验） |
| POST | `/auth/password-strength` | 认证 | 前端实时检测密码强度（body：{password}，返回 level/label/color/percent/valid） |
| GET | `/students/all` | 学生 | 学生列表（?keyword= 按姓名模糊查询，全量） |
| GET | `/students/page` | 学生 | 学生分页列表（?keyword=&page=&page_size=，默认 page=1、page_size=10，返回 {total, items}） |
| GET | `/students/one/{id}` | 学生 | 学生详情 |
| POST | `/students/add` | 学生 | 新增学生（body：{name, gender, age, grade, class_id?, teacher_id?, enrollment_date?}；分班时班级年级须与学生一致否则 400） |
| PUT | `/students/update/{id}` | 学生 | 修改学生（年级变更后若与所在班级年级不符，自动清空分班） |
| PUT | `/students/assign-class/{id}` | 学生 | 分班（body：{class_id}；只能选择与学生年级相同的班级，否则 400） |
| PUT | `/students/assign-teacher/{id}` | 学生 | 选老师（body：{teacher_id}，把学生分配给指定教师；teacher_id 传 null 可清空所选老师） |
| DELETE | `/students/del/{id}` | 学生 | 逻辑删除学生（移入回收站，记录操作人/删除时间） |
| GET | `/students/recycle/list` | 学生 | 回收站列表（管理员专属，需 X-Current-Role: admin；?keyword=&page=&page_size=，按删除时间倒序） |
| PUT | `/students/recycle/recover/{id}` | 学生 | 回收站恢复（管理员专属，从回收站还原学生） |
| DELETE | `/students/recycle/real-del/{id}` | 学生 | 回收站真实删除（管理员专属，物理删除学生及其选课记录、账号，不可恢复） |
| GET | `/teachers/all` | 教师 | 教师列表（?keyword= 按姓名模糊查询；返回含 职称名 zhicheng_name、授课课程数 course_count、班主任班级数 class_count、所带学生数 student_count、课时费总额 class_fee_total=单价×所带学生数、学历 education、入职日期 hire_date） |
| GET | `/teachers/one/{id}` | 教师 | 教师详情（同上含职称名、统计与新字段） |
| GET | `/teachers/{id}/detail` | 教师 | 教师完整详情（基本信息 + 授课课程 courses 列表 + 班主任班级 classes 列表 + 选其课程的学生 students 列表） |
| POST | `/teachers/add` | 教师 | 新增教师（body：{name, gender, age, subject, phone, zhicheng_id?, base_salary?, class_fee?, bonus?, education?, hire_date?, remark?}） |
| PUT | `/teachers/update/{id}` | 教师 | 修改教师（body 同新增，含 zhicheng_id?、薪资三字段与学历/入职日期/备注） |
| DELETE | `/teachers/del/{id}` | 教师 | 删除教师 |
| GET | `/classes/page` | 班级 | 班级分页列表（?keyword=&grade=&page=&page_size=，返回 {total, items}） |
| GET | `/classes/all` | 班级 | 班级列表（?keyword= 按班级名模糊查询，返回含 班主任名 head_teacher_name、在校学生数 student_count） |
| GET | `/classes/one/{id}` | 班级 | 班级详情（含班主任信息） |
| GET | `/classes/{id}/detail` | 班级 | 班级完整详情（班级 + 班主任 + 学生名单 + 男女统计） |
| POST | `/classes/add` | 班级 | 新增班级 |
| PUT | `/classes/update/{id}` | 班级 | 修改班级（变更年级时清空该班中年级不匹配学生的分班） |
| DELETE | `/classes/del/{id}` | 班级 | 删除班级 |
| GET | `/courses/all` | 课程 | 课程列表（?keyword= 按课程名模糊查询，返回含 状态/方式/人数上限/已选人数 enrolled_count） |
| GET | `/courses/one/{id}` | 课程 | 课程详情 |
| POST | `/courses/add` | 课程 | 新增课程（body 含 status/mode/max_students） |
| PUT | `/courses/update/{id}` | 课程 | 修改课程 |
| DELETE | `/courses/del/{id}` | 课程 | 删除课程（若会使某学生降到 0 门课程则返回 400 阻止） |
| GET | `/courses/student/{sid}` | 选课 | 查询学生已选课程 |
| GET | `/courses/students/{cid}` | 选课 | 查询某课程已选学生（含成绩，供成绩登记弹框） |
| POST | `/courses/select/{sid}` | 选课 | 学生选课（body：{course_id}；同一课程不能重复选，重复返回 400） |
| DELETE | `/courses/unselect/{sid}` | 选课 | 学生退课（?course_id= 指定课程；退掉最后一门课程返回 400） |
| PUT | `/courses/score/{sid}` | 选课 | 成绩登记（body：{course_id, score}，score 0-100） |
| GET | `/stats/class-count` | 统计 | 各班级人数统计（柱状图数据源） |
| GET | `/stats/gender-ratio` | 统计 | 在校学生男女占比（饼状图数据源） |
| GET | `/zhicheng/all` | 职称 | 职称列表（?keyword= 按职称名模糊查询，按级别倒序；返回含 对应教师数 teacher_count、对应教师名 teacher_names） |
| GET | `/zhicheng/one/{id}` | 职称 | 职称详情 |
| POST | `/zhicheng/add` | 职称 | 新增职称（body：{name, level, description}） |
| PUT | `/zhicheng/update/{id}` | 职称 | 修改职称 |
| DELETE | `/zhicheng/del/{id}` | 职称 | 删除职称（清空持有该职称教师的职称引用） |

## 5. 查询与分页参数

| 接口 | 参数 | 类型 | 说明 |
|------|------|------|------|
| `GET /xxx/all` | keyword | string | 按名称模糊查询（LIKE），可选 |
| `GET /students/page` | keyword | string | 按姓名模糊查询，可选 |
| `GET /students/page` | page | int | 页码，默认 1 |
| `GET /students/page` | page_size | int | 每页条数，默认 10（钳制 1~100） |
| `GET /students/recycle/list` | keyword / page / page_size | - | 回收站分页（管理员专属），按删除时间倒序 |
| `GET /classes/page` | keyword | string | 按班级名模糊查询，可选 |
| `GET /classes/page` | grade | string | 年级精确过滤（高一/高二/高三），可选 |
| `GET /classes/page` | page / page_size | - | 分页参数，默认 page=1、page_size=10 |

分页返回示例：
```json
{"code": 0, "msg": "成功", "data": {"total": 6, "items": [{"id": 1, "name": "张三", ...}]}}
```

## 6. 典型请求/响应示例

### 6.1 登录
```
POST /auth/login
{ "username": "admin", "password": "admin123" }

200 {"code": 0, "msg": "登录成功",
     "data": {"user_id": 1, "username": "admin", "role": "admin", "student_id": null}}
```

### 6.2 参数校验失败
```
POST /auth/register   （缺字段）

422 {"code": 422, "msg": "参数校验错误", "data": [{"type":"missing","loc":["body","username"],...}]}
```

### 6.4 新增学生
```
POST /students/add
{ "name": "张三", "gender": "男", "age": 15, "grade": "高一", "class_id": null, "teacher_id": null }

200 {"code": 0, "msg": "新增成功", "data": {"id": 19}}
```

### 6.5 学生回收站（管理员）
```
GET /students/recycle/list            # 需请求头 X-Current-Role: admin
PUT /students/recycle/recover/1       # 恢复学生，需 admin 头
DELETE /students/recycle/real-del/1   # 真实删除（不可恢复），需 admin 头

403 {"code": 403, "msg": "仅管理员可操作回收站", "data": null}
```
