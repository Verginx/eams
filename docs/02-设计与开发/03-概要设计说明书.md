## 1. 引言

本文档依据《软件需求规格说明书（SRS）》编写，描述系统总体架构、技术选型、分层结构与模块划分，指导详细设计与开发实现。

## 2. 技术选型

| 技术 | 版本要求 | 用途 | 选型理由 |
|------|---------|------|---------|
| Python + FastAPI | ≥0.110 | Web 框架 | 异步、自动校验、Swagger 文档、轻量 |
| PyMySQL | ≥1.1 | 数据库访问 | 手写 SQL，每次新建连接，教学直观 |
| Pydantic | ≥2.6 | 请求参数校验 | VO 校验、类型约束 |
| pydantic-settings | ≥2.0 | 环境配置 | .env 读取，配置外置 |
| MySQL 8.0 | ≥8.0 | 数据存储 | 项目指定 |
| Uvicorn | ≥0.29 | ASGI 服务器 | 本地开发运行 |
| HTML + JavaScript | - | 前端 | 原生无框架，资源分离 |

## 3. 系统架构

```
浏览器（HTML/JS 前端）
      │  HTTP / JSON（{code,msg,data}）
      ▼
FastAPI（main.py 挂载路由 + 中间件 + 异常处理）
      │
      ├─ 业务模块路由：auth / student / teacher / classes / course / stats / zhicheng
      │        └─ VO（请求校验）→ Model（数据访问）→ Database
      │
      └─ common 公共模块：db（每次新建连接）/ response / exceptions / logging / config
                              │
                              ▼
                     MySQL（school_db，7 张表）
```

- 前端页面由 FastAPI 挂载 `/static` 直接提供（Windows 本地单机部署，无 Nginx）
- 业务操作通过 `common/logging.py` 记录日志（app.log 按天滚动）
- 全局异常处理统一包装 `{code,msg,data}`

## 4. 分层设计

| 层 | 职责 | 位置 |
|----|------|------|
| Router（API） | 定义端点、调用 Model（实例方法）、组装响应 | `com/wanhe/<模块>/router.py` |
| Vo（校验模型） | 请求体字段与约束 | `com/wanhe/<模块>/vo.py` |
| Model（数据访问） | 手写 SQL，增删改查（实例方法） | `com/wanhe/<模块>/model.py` |
| Common（公共） | 每次新建连接、响应、异常、日志、配置 | `com/wanhe/common/` |

## 5. 模块划分

| 模块 | 说明 | 依赖 |
|------|------|------|
| auth | 注册/登录（用户名密码校验） | student（注册建学生）、common |
| student | 学生 CRUD + 分班 + 分页查询 | classes、common |
| teacher | 教师 CRUD + 查询 | common |
| classes | 班级 CRUD + 查询 | teacher、common |
| course | 课程 CRUD + 选课/查看选课 + 查询 | student、teacher、common |
| stats | 首页统计分析（各班级人数、男女占比） | common |
| common | db/response/exceptions/logging/config | 仅第三方 |

依赖单向无环：`auth→student→classes/teacher`、`course→student/teacher`、`stats→common`、各模块→common。

## 6. 前端架构

- 页面：`static/login.html`、`register.html`、`dashboard.html`
- 资源分离：`static/css/`（common/auth/dashboard）、`static/js/`（common/login/register/dashboard）
- `common.js`：共享 `api()`（envelope 解析、错误处理）与 `logout()`，无 token 机制
- 后台布局：顶栏 + 左侧边栏（首页/学生/教师/课程/班级）+ 内容区
- 首页面板：欢迎语 + 4 项统计卡片
- 交互：新增/修改弹框、列表查询、学生分页、分班下拉绑定、选课勾选/下拉绑定、表单前端校验

## 7. 关键设计决策

- **统一响应**：所有接口返回 `{"code":0,"msg","data"}`，错误时 code=HTTP 状态码、data=null，由全局异常处理器统一生成
- **无鉴权**：教学演示，所有管理接口可直接访问（无 JWT/token）
- **数据库**：`common/db.py` 仿 database.py 风格，每次新建连接、方法内 commit，无连接池
- **Model**：实例方法（非 staticmethod），无实例状态
- **日志**：`common/logging.py` 配置 app.log 按天滚动保留 7 天，业务操作写日志
- **配置外置**：`pydantic-settings` 读 `.env`，缺省值兼容本地默认
