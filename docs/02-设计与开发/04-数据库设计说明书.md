## 1. 概述

## 2. 表结构

## 3. 表间关系

```
users (1) ── 关联 ──> (1) students
teachers (1) ── 职称 ──> (0..1) zhicheng
teachers (1) ── 班主任 ──> (0..n) classes
teachers (1) ── 授课 ──> (0..n) courses
teachers (1) ── 带生 ──> (0..n) students   (通过 students.teacher_id 选老师)
students (1) ── 选课 ──> (n..m) courses   (通过 student_course 中间表)
```

## 4. 关键约束与设计

- `users.username` 唯一索引；`users.role` 区分 admin / student
- `student_course` 联合唯一键 `(student_id, course_id)` 防重复选课
- `courses.credit` 默认 1；`courses.status/mode/max_students` 分别默认 开课/线下/NULL
- **学生老师 = 直接关联**：学生通过 `students.teacher_id` 直接选定一名教师（选老师功能，学生列表展示「所选老师」）；与选课无关，一名教师可带多名学生
- **选课**：学生可多选课程（至少 1 门），通过 `student_course` 关联 `courses.teacher_id` 取得授课教师
- **至少一门课**：每个学生至少选择 1 门课程；退课不能退掉最后一门、删除课程不能使某学生降到 0 门（接口层拦截）
- **课时费总额**：`class_fee_total = class_fee（单价）× 所带学生数`，列表/详情动态计算；此处「所带学生数」= **选择该教师所授课程的去重学生数**（经 `student_course` + `courses.teacher_id` 统计，与 `students.teacher_id` 的选老师互不影响）
- **学生回收站（逻辑删除）**：`students.is_deleted/delete_time/delete_operator` 记录软删除信息，回收站支持恢复与真实删除（真实删除为物理删除，需管理员权限）
- **年级固定与约束**：
  - 班级年级固定（高一/高二/高三）；学生年级与班级年级一致（分班只能选择与学生年级相同的班级）
  - 教师职称越高薪资越高、所带年级越高：中级→高一、副高级→高二、高级→高三（班主任配置）
  - 年龄↔年级软规则（种子数据一致：高一 15、高二 16、高三 17），接口不强制
- **一致性清理**：学生/班级改年级导致年级不匹配时，自动清空该生分班
- **级联删除**（逐条执行）：
  - 真实删学生（回收站）：`student_course` → `users` → `students`
  - 删课程：`student_course` → `courses`
  - 删教师：清空 `courses.teacher_id` / `classes.head_teacher_id` / `students.teacher_id` → 删教师
  - 删班级：清空 `students.class_id` → 删班级
  - 删职称：清空 `teachers.zhicheng_id` → 删职称
- 关联查询（JOIN）：学生列表 LEFT JOIN classes 取班级名 + LEFT JOIN teachers 取教师名（students.teacher_id）与选课数子查询；教师列表 LEFT JOIN zhicheng 取职称名 + 课程/班级/所带学生数/课时费总额子查询；班级列表 LEFT JOIN teachers 取班主任名 + 在校学生数子查询；职称列表子查询取对应教师数与教师名；教师详情按教师返回授课课程/班主任班级/选其课程的学生列表

## 5. 种子数据

| 类型 | 数量 | 说明 |
|------|------|------|
| 学生 | 18 | 每班 3 人（6 班），年龄随年级（高一 15 / 高二 16 / 高三 17） |
| 教师 | 6 | 张/李(中级，高一班主任)、王/赵(副高级，高二班主任)、孙/周(高级，高三班主任)，薪资随职称递增，含学历/入职日期/备注 |
| 班级 | 6 | 高一(1)(2)班、高二(1)(2)班、高三(1)(2)班 |
| 课程 | 6 | 数学/语文/英语/物理/化学/生物 |
| 选课 | 全部 18 人 | 每人均选 1-3 门课程（每个学生至少选 1 门），各教师所带学生数有差异 |
| 职称 | 4 | 初级(1)/中级(2)/副高级(3)/高级(4) |
| 用户 | 1 | admin / admin123（role=admin，明文种子密码可直接登录） |
