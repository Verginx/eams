## 2. 功能实现总结

| 模块 | 实现要点 |
|------|---------|
| 认证 | 注册（明文存储）、登录（用户名密码校验）、无鉴权 |
| 学生 | CRUD、分班/选老师下拉绑定、关键字查询、分页（每页 10） |
| 教师 | CRUD、关键字查询 |
| 班级 | CRUD、关键字查询、班主任下拉 |
| 课程选课 | 课程 CRUD、选课下拉绑定、查看学生选课、关键字查询 |
| 系统 | 统一响应、全局异常、每次新建连接、逐条级联删除、业务日志、.env 配置 |

## 4. 已知限制与后续规划

| 类别 | 事项 |
|------|------|
| 权限 | 系统无鉴权，所有接口可直接访问；后续可加角色级权限（admin 专用） |
| 功能 | 退课、成绩登记前端入口待接（接口已提供） |
| 架构（P1） | 可引入 SQLAlchemy + Alembic 迁移、service 分层、依赖注入 |
| 可观测性（P2） | 可加结构化日志 + request_id、/health 探针、Prometheus 指标 |
| 测试 | 当前通过 Apifox 接口测试工具验证（无自动化测试） |

## 5. 总结

系统已实现需求文档定义的核心教务管理功能，前后端分离、安全与可观测基础完备，符合教学演示与轻量内部使用定位。待部署环境完成真实数据库全流程验收后即可投入使用。
