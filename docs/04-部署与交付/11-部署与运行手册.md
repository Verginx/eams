## 1. 环境要求

- Windows 10/11
- Python 3.10+（安装时勾选 Add to PATH）
- MySQL 8.0+（本机安装并启动 MySQL 服务）
- 推荐 GUI 工具：Navicat 或 MySQL Workbench（可视化操作数据库）、PyCharm（可视化创建虚拟环境 / 运行）

## 2. 部署步骤（可视化操作）

| 步骤 | 可视化操作 | 说明 |
|------|-----------|------|
| 1. 初始化数据库 | Navicat/Workbench 新建连接（127.0.0.1:3306，root/密码）→ 打开项目根 `init.sql` → 执行全部 | 创建 `school_db` + 7 表 + 种子数据 |
| 2. 准备配置 | 记事本/VS Code 打开项目根 `.env`（已存在）→ 按本机 MySQL 改 `DB_PASSWORD`（必要时 `DB_USER`/`DB_PORT`）→ 保存 | 若 `.env` 缺失按下方模板新建 |
| 3. 虚拟环境 + 依赖 | PyCharm：Open 项目 → Settings → Project → Python Interpreter → Add Interpreter → 新建 Virtualenv → OK → 终端 `pip install -r requirements.txt` | 装 5 个依赖包 |
| 4. 启动服务 | PyCharm 右键 `main.py` → Run 'main'（或 Add Configuration 用 uvicorn 模块） | 出现 `Uvicorn running on http://127.0.0.1:8000` 即成功 |
| 5. 访问 | 浏览器打开 `http://127.0.0.1:8000`；文档 `http://127.0.0.1:8000/docs` | 用 `admin/admin123` 登录 |

### 命令行替代（不想用 GUI 时）

```bash
mysql -uroot -p < init.sql
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload      # 或 python main.py
# 访问 http://127.0.0.1:8000
```

## 3. .env 配置项

| 配置项 | 默认 | 说明 |
|--------|------|------|
| DB_HOST | 127.0.0.1 | 数据库地址 |
| DB_PORT | 3306 | 端口 |
| DB_USER | root | 用户名 |
| DB_PASSWORD | 150259 | 密码（按本机修改） |
| DB_NAME | school_db | 数据库名 |

## 4. 日志说明

- 输出目录：项目根 `logs/`
- `app.log`：业务操作日志（登录/注册/增删改/选课等），按天滚动保留 7 天（当天写 app.log，每天午夜切换）
- 均按天滚动（`when=midnight`），保留 7 天

## 5. 默认账号

| 角色 | 用户名 | 密码 |
|------|--------|------|
| 管理员 | `admin` | `admin123` |

> 学生注册入口：登录页「去注册」。明文种子密码登录成功后明文存储。

## 6. 常见问题

| 问题 | 处理 |
|------|------|
| 查询接口报 500 连接失败 | 检查 MySQL 服务已启动、.env 的 DB_HOST/DB_PASSWORD 正确 |
| 访问管理接口 | 系统无鉴权，直接访问即可 |
| 端口 8000 被占用 | 改用 `uvicorn main:app --port 8000 其他端口` |
