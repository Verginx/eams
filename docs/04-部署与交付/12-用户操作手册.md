## 1. 概述

本手册指导用户使用 EAMS 系统：注册登录、查看首页统计、完成学生/教师/课程/班级/职称管理与教务绑定操作。

## 2. 登录与注册

### 2.1 登录
1. 浏览器打开 `http://127.0.0.1:8000`（或由系统管理员提供地址）
2. 输入用户名、密码，点击「登 录」
3. 登录成功后自动进入后台首页

### 2.2 注册（学生）
1. 登录页点击「去注册」
2. 填写用户名（3-20 位）、密码（6-20 位）、姓名、性别、年龄（10-100）
3. 点击「注 册」，成功后返回登录页登录

> 表单必填与范围由系统校验，空/非法输入会给出中文提示。

## 3. 后台首页

登录后进入首页面板，显示：
- 欢迎语（当前用户名 + 角色）
- 统计卡片：学生总数 / 教师总数 / 课程总数 / 班级总数

左侧边栏可切换：首页 / 学生管理 / 教师管理 / 课程管理 / 班级管理 / 职称管理；右上角可「退出」。

## 4. 学生管理

| 操作 | 步骤 |
|------|------|
| 查询 | 顶部输入「按姓名搜索」→ 点「查询」；「重置」清空回到第 1 页 |
| 分页 | 底部「上一页 / 下一页 / 页码」翻页 |
| 新增 | 点「新增学生」→ 弹框填姓名/性别/年龄并选择年级，班级下拉仅显示该年级班级（也可暂不分班）→ 确定 |
| 编辑 | 行内「编辑」→ 弹框预填修改 → 确定（若年级改为与所在班级不符，系统自动清空该生分班） |
| 分班 | 行内「分班」→ 弹框仅显示与学生学习年级一致的班级 → 确定（跨年级班级不可选） |
| 选课 | 行内「选课」→ 弹框勾选课程（老师 = 所选课程授课教师；学生至少需选 1 门课程）→ 确定 |
| 删除 | 行内「删除」→ 确认 → 连带清理选课记录与账号 |

## 5. 教师管理

- 「按姓名搜索」查询 / 重置
- 「新增教师」弹框录入姓名、性别、年龄、科目、电话、学历（本科/硕士/博士）、入职日期、备注（均含可选），并可下拉选择职称（如：初级/中级/副高级/高级，也可暂不评定）
- 弹框可填写薪资待遇：基本工资（月薪）、课时费单价（每学生，总额 = 单价 × 所带学生数）、奖金/津贴（均可留空）
- 列表展示 学历、入职日期、职称、基本工资、课时费（总额）、奖金、所带学生数
- 行内「详情」弹框查看该教师基本信息、授课课程名单、班主任班级名单、选其课程的学生名单
- 行内「编辑」修改（含职称下拉、薪资与学历/入职日期/备注，可点「撤销」放弃修改返回列表）、「删除」确认删除（删除后其授课课程、班主任班级会被清空，选其课程的学生将失去该课程）

## 6. 课程管理

- 「按课程名搜索」查询 / 重置
- 「新增课程」弹框录入课程名、学分（1-10）、授课教师
- 行内「编辑」修改、「删除」删除课程（连带选课记录）
- 行内「选课」→ 弹框标题显示课程与授课教师，下拉选择学生（显示学生所在班级与已选课数）→ 确定（同一课程不能重复选给同一学生）
- 行内「成绩」→ 弹框列出该课程已选学生，逐个填写成绩（0-100，留空表示不修改）→ 确定
- 「查看学生选课」→ 弹框下拉选择学生 → 展示该学生已选课程（含成绩），每门课右侧可点「退课」退选（每个学生至少选 1 门课程，退掉最后一门会被拦截）

## 7. 班级管理

- 「按班级名搜索」查询 / 重置
- 「新增班级」弹框录入班级名、年级、班主任（下拉）
- 行内「编辑」修改、「删除」删除班级（删除后所属学生自动变为「未分班」；变更年级时，该班中年级不匹配学生自动清空分班）

## 8. 职称管理

- 「按职称名搜索」查询 / 重置
- 列表展示 对应教师（持有该职称的教师姓名，多个用「、」分隔；无教师显示「无教师」）
- 「新增职称」弹框录入职称名称、级别（1-10，越大越高）、说明
- 行内「编辑」修改、「删除」删除职称（删除后持有该职称的教师自动变为「未评定」）

## 9. 退出登录

点击右上角「退出」，系统清除登录状态并返回登录页。

## 10. 常见问题

| 问题 | 说明 |
|------|------|
| 无需登录即可访问后台 | 系统无鉴权（教学演示），直接进入即可 |
| 操作后列表未更新 | 刷新页面或重新点击对应管理菜单 |
