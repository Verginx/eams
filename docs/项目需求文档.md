## 一、项目概述

EAMS（Education Administration Management System）学校教务管理系统，基于 Web 的教务管理系统，实现学生、教师、课程、班级的信息化管理，支持学生在线注册、选课、选老师、分班等核心教务流程。

- **技术栈**：Python + FastAPI、PyMySQL、Pydantic + pydantic-settings、用户名密码校验、MySQL 8.0、原生 HTML/JS、Uvicorn
- **架构**：业务模块（auth / student / teacher / classes / course / stats）+ 公共模块（common），前后端资源分离，统一响应 `{code,msg,data}`，登录采用用户名密码校验

## 三、功能需求摘要

| 模块 | 功能编号 | 摘要 |
|------|---------|------|
| 认证 | AUTH-01~02 | 学生注册（明文）、登录（用户名密码校验） |
| 学生 | STU-01~07 | 增删改查、分班/选老师下拉绑定、关键字查询、分页 |
| 教师 | TEA-01~05 | 增删改查、关键字查询、职称下拉绑定、薪资待遇（基本工资/课时费/奖金）、列表含职称/薪资/授课/班级/学生统计、删除时清空课程/班级/学生引用 |
| 班级 | CLS-01~05 | 增删改查、关键字查询、班主任下拉、删除时清空学生班级引用 |
| 课程选课 | COU-01~11 | 课程增删改查、选课下拉、查看学生选课（可退课）、成绩登记、关键字查询 |
| 职称 | ZC-01~05 | 增删改查、关键字查询、级别管理、列表显示对应教师名、删除时清空教师职称引用 |
| 统计 | DSH-01~03 | 后台首页欢迎语 + 4 项统计 + 班级人数柱状图 + 男女占比饼状图 |

> 详细功能需求与验收标准见 [02-软件需求规格说明书-SRS](01-立项与需求/02-软件需求规格说明书-SRS.md)。

## 四、非功能需求摘要

安全（密码明文存储、配置经 .env 注入）、数据一致性（级联删除逐条执行）、容错（统一 envelope）、可观测（app.log 按天滚动（业务操作日志））、前端交互（查询/分页/弹框/下拉/前端校验防 422）、可维护性（模块分层）。

## 五、数据库摘要

`school_db`，7 张表：`users / teachers / classes / students / courses / student_course / zhicheng`；种子数据 6 学生 / 4 教师 / 4 班级 / 4 课程 / 3 选课 / 4 职称 / 1 管理员。详见 [04-数据库设计说明书](02-设计与开发/04-数据库设计说明书.md)。

## 六、接口摘要

业务接口 37 个（加根路径共 38 条路径），统一响应 `{code,msg,data}`，系统无鉴权，所有接口可直接访问；支持 `?keyword=` 查询、学生分页 `/students/page`、按课程查学生 `/courses/students/{id}`、退课 `?course_id=`。详见 [05-接口设计说明书](02-设计与开发/05-接口设计说明书.md)。

## 七、页面摘要

登录页 / 注册页 / 管理后台（首页 + 学生/教师/课程/班级/职称管理），前端资源分离（css/js），纯原生无框架，用户输入经 HTML 转义防 XSS。详见 [12-用户操作手册](04-部署与交付/12-用户操作手册.md)。

## 八、部署摘要

Windows 本地部署：`init.sql` 建库 → 配置 `.env` → `pip install -r requirements.txt` → `uvicorn main:app`。默认账号 `admin / admin123`。详见 [11-部署与运行手册](04-部署与交付/11-部署与运行手册.md)。
